# Notification Settings

Choose which notifications you receive.

## Accessing Settings

1. Open **Settings** from your account menu
2. Scroll to the **Notifications** card

Changes save automatically as you toggle each option — there's no separate save button. If a change can't be saved, the toggle switches back.

## Email Notifications

Delivered to your account email:

| Option | Description |
|--------|-------------|
| **Agent run notifications** | Agent execution completed or failed |
| **Product updates** | New features, improvements and releases |
| **Marketing** | Promotions, tips and special offers |

## In-App Notifications

Shown inside Hyver (the badge and the Notifications page):

| Option | Description |
|--------|-------------|
| **System notifications** | System announcements and alerts |
| **Agent run notifications** | Agent execution completed or failed |

## Tips

- Keep **Agent run notifications** on so you know when your tasks finish or need approval
- Turn off **Marketing** if you'd prefer fewer emails
