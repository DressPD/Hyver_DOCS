# Files & Skills Panel

The **Files & Skills** panel sits beside your chat and keeps your documents and reusable prompts one click away. It replaces the old standalone Files page and knowledge-base toggle.

## Opening the Panel

Use the panel button in the chat header (**Expand file panel** / **Collapse file panel**). Drag its edge to resize it. It has two tabs: **Files** and **Skills**.

## Files Tab

### Browse and Organize

- The breadcrumb starts at **Home**; click a folder to open it
- **New Folder** — name it and confirm
- **Upload** — add a document to the current folder

An empty folder shows **This folder is empty**.

### Each File

| Control | What it does |
|---------|--------------|
| **Active / Inactive** | Turns the file on or off for the AI without deleting it |
| **Pin to chat** / **Unpin from chat** | Attaches the file to the current chat (or removes it) |
| **Download** | Opens a download link |
| **Delete** | Removes the file — you'll be asked to confirm, and it can't be undone |

Files the AI creates during a chat show up here too, so you can download them later.

### Using Files in Chat

Type `/file/` in the message box and pick a document, then ask about it. See [Sending Messages](messages.md). A chat can have up to 5 session files.

## Skills Tab

- **New Skill** — opens the skill form; see [Create a Skill](../skills/create.md)
- **Your skills** — skills you created. Click one to edit or delete it.
- **Public skills** — skills shared with everyone. Those curated by Hyver carry an **Official** badge.

Launch any skill from chat with `/skill/` — see [Find & Use Skills](../skills/browse.md).

## Tips

- Name files descriptively so they're easy to find with `/file/`
- Use folders to keep unrelated projects apart
- Mark files **Inactive** instead of deleting them if you only need a break from them
