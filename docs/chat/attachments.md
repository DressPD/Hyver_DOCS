# Attachments

Hyver supports two kinds of material in chat:

1. **Image attachments** — images sent with a single message
2. **Files** — documents you keep in the [Files & Skills panel](files-panel.md)

## Image Attachments

Attach images to the message you're about to send:

1. Click the **Attachment** button in the composer, or **paste** an image directly into the message box
2. Images appear as thumbnails above the input while they finish processing
3. Send your message — the images go with it

**Notes:**
- Common image formats are supported (PNG, JPG, GIF, WebP, and similar)
- You can attach up to **3 images** per message
- Image input is available when the active model supports images; if it doesn't, the attachment button is hidden
- Click an image in the conversation to open it larger

## Files

To give the AI a document:

1. Open the **Files** tab of the [Files & Skills panel](files-panel.md) and **Upload** it
2. Reference it in a message with **`/file/`** and the file name

A chat can have up to **5 session files** at a time, and you need to have started a chat before uploading. If an upload is rejected, the message tells you whether the file type, size, or file count was the problem.

## Using Attachments in Chat

Once an image or file is attached:

1. Reference it in your message: "Based on the uploaded PDF…" or "What's in this screenshot?"
2. The AI reads and analyses the content
3. Ask questions about specific sections, data, or details

## Tips

- **File size** - Large files may take longer to process
- **Naming** - Name files descriptively so they're easy to find with `/file/`
- **Format** - Use standard formats for best compatibility
- **Sensitive data** - Be mindful of what you upload
