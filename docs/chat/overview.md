# Chat Overview

Chat is the heart of Hyver — your workspace for interacting with AI.

## What You Can Do

- **Send messages** to the AI directly
- **Attach images** for the AI to analyse in the current message
- **Keep files and skills at hand** in the [Files & Skills panel](files-panel.md)
- **Run skills** with `/skill/` to apply a reusable prompt template
- **Use tools** with `/tool/` to let the AI call external services
- **Reference files** with `/file/`
- **Approve tool actions** before they run — see [Tool Approvals](approvals.md)
- **Configure the model** and the reasoning and search toggles for each conversation
- **View activity** to watch the AI's reasoning and tool use in real time

## Chat Interface

### Message Area
The central area shows your conversation history. Your messages appear on the right, AI responses on the left, streamed in real time. Long tool output, screenshots, and files the AI produces appear inline as cards and artifacts.

### Message Composer
At the bottom of the screen:
- **Text input** — Type your message (Shift+Enter for a new line)
- **Send button** — Send your message (or press Enter). If a run is still resuming, new messages are queued and sent when it's ready.
- **Stop button** — Interrupt a response in progress
- **Attachment button** — Attach images
- **Microphone** — Dictate your message with voice input (Chrome or Edge)
- **Slash commands** — Type `/` for skills (`/skill/`), tools (`/tool/`), files (`/file/`), and `/help`

### Navigation Sidebar
Quick access to your **Recent chats** and Tasks.

## Creating Chats

### New Chat
Click **New chat** in the navigation sidebar to start a fresh conversation.

### From a Skill
Type `/skill/` in any chat, or open the **Skills** tab in the [Files & Skills panel](files-panel.md).

## Managing Chats

### Past Conversations
Click **View all conversations** under **Recent chats** (or the history button) to open the **Recent conversations** page, where you can open, rename, or remove saved conversations.

### Rename
Open a chat's context menu in the sidebar and select **Rename**, or use **Rename conversation** on the conversations page.

### Delete
Open the chat context menu and select **Delete**. This cannot be undone.

## Your Workspace

The first message of a session may start your personal workspace in the background. You can keep chatting meanwhile; see [Activity Pane](activity.md) for the workspace status.
