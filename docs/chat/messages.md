# Sending Messages

## Basic Messaging

1. Click in the message box at the bottom of the chat
2. Type your message
3. Press **Enter** or click the **Send** button

The AI begins responding immediately and streams the reply in real time.

## Stop Generation

If the AI is going in the wrong direction:
- Click the **Stop** button that appears during generation
- The AI stops and you can send a follow-up

## Voice Input

Prefer to speak? Click the **microphone** button and dictate your message. Your speech is transcribed into the message box as you talk; click it again to stop. Voice input works in Chrome and Edge, and needs microphone permission.

## Slash Commands

Type `/` in the message box to open the command menu. Suggestions are grouped into **Skills**, **Tools**, **Files**, and **Commands**. Use ↑ ↓ to move and **Enter** to select:

- **`/skill/`** — Search skills. Selecting one pre-fills the composer with the skill's prompt template so you can edit and send it.
- **`/tool/`** — Search available tools. Selecting one activates it for the conversation; the AI then calls it when relevant.
- **`/file/`** — Search your files and reference one in your message. File names with spaces work too (for example `/file/My Report.pdf`).
- **`/help`** — List the available commands.

## Sending While the AI Is Busy

If a run is still resuming or recovering, messages you send are **queued** and go out as soon as the workspace is ready. If a send fails, Hyver backs off and retries instead of dropping the message.

## Tips for Better Responses

### Be Specific
Instead of "Help me with my code", try "Debug this Python function that's raising a TypeError on line 12".

### Provide Context
Include relevant background information, especially for complex tasks.

### Break Down Complex Tasks
For large tasks, start with one step at a time rather than asking for everything at once.

### Use Skills for Repeat Work
If you find yourself typing the same setup instructions often, save them as a skill and launch it with `/skill/`.

## Conversation Continuity

Hyver remembers your conversation history within each chat. You can:
- Reference earlier messages ("As I mentioned before...")
- Build on previous responses
- Return to old chats and continue where you left off
