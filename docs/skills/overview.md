# Skills Overview

Skills are reusable prompt templates that let you launch proven workflows instantly.

## What is a Skill?

A skill is a saved prompt template that:

- **Speeds up repeat work** — start from a polished prompt instead of rewriting it
- **Captures expertise** — preserve the best instructions for a task
- **Stays consistent** — the same framing, every time

Think of a skill as a launch-ready workflow block for prompting.

## Where Skills Live

Skills are managed from the **Skills** tab of the [Files & Skills panel](../chat/files-panel.md) in chat — there's no separate Skills page:

- Click **New Skill** to create one
- Click one of **Your skills** to edit or delete it
- Browse **Public skills** shared with everyone

In chat, type **`/skill/`** to search and launch any skill.

## Your Skills vs Public Skills

### Your Skills
Skills you created — fully editable, and always **private** to you. Sharing skills to the marketplace isn't available yet.

### Public Skills
Skills available to everyone. Those curated by Hyver carry an **Official** badge.

## Using a Skill

Type **`/skill/`** in the message box, pick a skill, and its prompt pre-fills the composer. Edit it if you like, then send.

## Skill Components

| Component | Role |
|-----------|------|
| **Name** | Clear title for the workflow |
| **Description** | Explains when to use the skill |
| **Category** | Groups similar workflows |
| **Prompt template** | The reusable instructions the AI receives; supports `{{variables}}` for parameterised inputs |
