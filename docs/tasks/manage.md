# Managing Tasks

Run, retry, schedule, and clean up your tasks from the Tasks feed.

## Launching a Task

1. Type a prompt in the launch box at the top of the Tasks page
2. Press **Enter** or click **Launch** to run it now

You'll see **Task launched — tracking it in your feed**. The new task appears in the feed and streams its result; open it any time to read the full conversation.

## Scheduling a Task

1. Type a prompt in the launch box
2. Click **Schedule** — or type a phrase like "every weekday at 8am" and the schedule panel opens automatically
3. Choose how often it **Repeats** — **Daily**, **Weekdays**, **Weekly**, or **Monthly** — and the **Day** (for weekly and monthly) and **Time**
4. Launch

You'll see **Schedule created — it will run automatically**, and the task appears under **Scheduled**.

## Card Actions

Which actions appear depends on the task's status:

- **Approve / Reject** — respond to a tool the AI wants to run (Needs approval)
- **Cancel** — stop a running task (In progress)
- **Retry** — re-run the last prompt (Failed)
- **view result / view progress / View** — open the task's chat
- **edit schedule**, **Pause / Resume**, **Run now** — manage a scheduled task
- **Delete** — remove a task

**Run now** triggers a scheduled task immediately without changing its schedule. The card updates as the run starts, so give it a moment.

> ⚠️ Deleting a task also deletes its chat history and cannot be undone. Deleting a scheduled task stops it running and deletes its chat history too. You'll be asked to confirm first.

## Renaming a Task

A task's title comes from its linked chat. To rename it, open the chat and rename it from **Recent chats** in the sidebar.

## Finding Tasks

### Filter by status
Click a stat tile at the top of the page to show only tasks in that state.

### Search
Use the search box (or press `/`) to match tasks by name, category, or skill. A match count appears while you search.

## Tips

- Give prompts a clear first line — it becomes the task title
- Check failed tasks and use **Retry** to run them again
- Use **Run now** to test a schedule before waiting for its next run
