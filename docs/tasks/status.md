# Task Status

Every task falls into one of these states, shown as tiles at the top of the Tasks page and as sections in the feed.

## Needs Approval

The AI is waiting for your permission to use a tool. A task can also be marked **Authentication required** (a service needs connecting) or **Handoff required**.

**What you can do:** **Approve** or **Reject** the requested action right on the card, or open the task to review it first. See [Tool Approvals](../chat/approvals.md).

## In Progress

The task is actively running — the AI is generating a response or using tools. The card shows **Running**.

**What you can do:** **view progress** to watch it, or **Cancel** to stop it (Cancel is disabled once a run can no longer be cancelled).

## Failed

Something went wrong — an error, a timeout, or a processing problem. A task you cancelled shows as **Cancelled**.

**What you can do:** **Retry** to run the last prompt again, **View** to see the error, or **Delete** the task.

## Scheduled

A recurring task set to run automatically. It shows **Scheduled**, or **Paused** if you paused it.

**What you can do:** **edit schedule**, **Run now**, **Pause** / **Resume**, open the linked chat, or **Delete** it.

## Completed

The task finished successfully and shows **Done**.

**What you can do:** **view result** to read it, or delete the task.

## Filtering by Status

Click any stat tile to show only that state; the **Total** tile (with **show all**) clears the filter. Relative timestamps like "2m ago" and "Next run: in 3h" refresh automatically, and the feed updates as job statuses change.
