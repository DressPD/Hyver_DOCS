# Tasks Overview

The **Tasks** page — **Autopilot** — is where you hand work to Hyver: launch it now or on a schedule, then approve and track everything from a single feed.

## What is a Task?

A task is any AI job you run:

- A **prompt you launch** from the Tasks page
- A **scheduled** job that runs on a recurring basis

Each task is tied to a chat, so you can open it to see the full conversation.

## Accessing Tasks

Click **Tasks** in the navigation sidebar.

## The Layout

### Launch Box
At the top, under **What do you want done?**, type a prompt — for example "Send me a competitor pricing recap every Monday at 9am" — and:

- Click **Launch** (or press Enter) to run it now
- Click **Schedule** to run it on a recurring basis; typing a phrase like "every day at 9am" opens the schedule panel automatically

### Stat Tiles
Tiles show how many tasks are in each state — **Needs your approval**, **In progress**, **Failed**, **Scheduled**, **Completed**, plus a **Total**. Click a tile to filter the feed to that state; click again (or **show all**) to clear the filter.

### Feed
Your tasks appear as cards grouped by status, each section with a hint (for example "blocking — review before anything else"). Use the **search** box (or press `/`) to filter by name, category, or skill, and collapse a section to tidy things up. Until you've launched anything, the feed shows **Nothing on autopilot yet** with a **Start your first task** button.

## Skills

Reusable prompts are managed from chat — see [Skills](../skills/overview.md). To run a skill's prompt, launch it with `/skill/` in a chat.
